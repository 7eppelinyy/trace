## 回滚

先备份当前改版，再从 Git 标签恢复 `miniprogram/` 和 `project.config.json`：

```powershell
git restore --source backup/client-pre-apple-v2-20261004 -- miniprogram project.config.json
```

本机私有开发工具设置可从旧版 ZIP 单独恢复。运行时访客账户、缓存、自选数据库和后端数据均不在这个源码回滚范围内。
