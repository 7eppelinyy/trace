## 5. N02：完成会话续期与账户/缓存隔离

**优先级：P0；入口：** `trace/api/routers/auth.py`、`trace/db/repositories.py:UserSessionRepo`、`trace/api/deps.py`、`trace/api/security.py`、`miniprogram/utils/api.js`、设置页。

当前明确缺口：设备访客 access token 为 30 天；过期后客户端要求重置成新账户。服务端旧数据还在，但用户无法继续访问。此前尝试的 0028 会话刷新 patch **没有成功落地**，不要以为表/接口已经存在。

建议确定契约：

```text
POST /auth/session
  guest -> access token + refresh credential + 同一服务端 user_id
  dev   -> 仅显式开发开关，production 永不允许
  wechat -> 未接入真实平台校验前继续明确 unavailable/501

POST /auth/session/refresh
  refresh credential -> 新 access + 轮换后的 refresh，user_id 保持不变

DELETE /auth/session
  撤销当前会话与对应刷新能力
```

精确步骤：

1. 先列迁移目录。为 refresh 能力追加迁移，建议保存 `token_hash/user_id/family_id/expires_at/used_at/revoked_at/created_at`；不保存可直接使用的 refresh 明文。
